# Security Policy

## Supported Versions

Only the latest version of each sample in this repository is supported. Please make sure you are on the
latest `dev` branch before reporting an issue.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them via [GitHub Security Advisories](https://github.com/aziontech/azion-samples/security/advisories/new):

1. Go to the [Security tab](https://github.com/aziontech/azion-samples/security) of this repository
2. Click **Report a vulnerability**
3. Fill out the vulnerability report form

If you are unable to use GitHub Security Advisories, email us at security@azion.com.

Please include as much of the following information as possible:

- The affected sample and file path(s)
- A description of the vulnerability and its potential impact
- Step-by-step instructions to reproduce the issue
- Proof-of-concept code, if available
