# Postgres SvelteKit Starter

Simple SvelteKit template that uses a NeonDB (Postgres) database.

## One-Click Deploy

[![Deploy Button](https://www.azion.com/button.svg)](https://console.azion.com/create/svelte/postgres-sveltekit "Deploy with Azion")

## How to Use

In order to use this template you must have a NeonDB account. You can create one for free at [Neon](https://neon.tech/).

Once you have a NeonDB account, you can create a new database and get the connection string. You can find the connection string in the NeonDB dashboard under the "Connection strings" section.

Copy the connection string and paste it into the `.env` file in the root of the project.
