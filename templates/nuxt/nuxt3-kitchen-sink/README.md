# Nuxt 3 Kitchen Sink Template

This template is an open-source, customizable template built with Nuxt 3 and Tailwind CSS.

Look at the [Nuxt 3 documentation](https://nuxt.com) to learn more.

## Supported Features

- Server-Side Rendering (SSR)
- Server Routes
- Teleports
- Middleware
- Edge Rendering
- Nuxt Loading Indication
- `NuxtLink`
- `NuxtContent`
- Data Fetching
